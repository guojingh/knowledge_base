## 2.问题描述

**本次是在部署该项目后发现，服务不能支持并发访问，因此使用在作者原始代码的基础上做了一些修改，达到让该服务拥有支持并发的能力。**

即：在请求访问 arxiv_search/google_scholar 工具等待的过程中，其余请求都会被阻塞，包括 tool_list 的请求。

### 1.原因

源码如下：

```python
from mcp.server.models import InitializationOptions
import mcp.types as types
from mcp.server import NotificationOptions, Server
import mcp.server.stdio
from .arxiv_search import ArxivSearch
from .google_scholar import GoogleScholar

server = Server("mcp-scholarly")

@server.list_tools()
async def handle_list_tools() -> list[types.Tool]:
    """
    List available tools.
    Each tool specifies its arguments using JSON Schema validation.
    """
    return [省略....]

@server.call_tool()
async def handle_call_tool(
        name: str, arguments: dict | None
) -> list[types.TextContent | types.ImageContent | types.EmbeddedResource]:
    """
    Handle tool execution requests.
    Tools can modify server state and notify clients of changes.
    """
    if name != "search-arxiv" and name != "search-google-scholar":
        raise ValueError(f"Unknown tool: {name}")

    if not arguments:
        raise ValueError("Missing arguments")

    keyword = arguments.get("keyword")

    if not keyword:
        raise ValueError("Missing keyword")

    # Notify clients that resources have changed
    await server.request_context.session.send_resource_list_changed()

    formatted_results = []
    if name == "search-arxiv":
        arxiv_search = ArxivSearch()
        formatted_results = arxiv_search.search(keyword)
    elif name == "search-google-scholar":
        google_scholar = GoogleScholar()
        formatted_results = arxiv_search.search(keyword)

    return [
        types.TextContent(
            type="text",
            text=f"Search articles for {keyword}:\n"
                 + "\n\n\n".join(formatted_results)
        ),
    ]
```

### 2.分析

在handle_call_tool() 里面，if name == "search-arxiv": 这里通过工具名称进行调用的时候，原始代码如下：

```python
# 原始代码
async def handle_call_tool(...):
		arxiv_search.search(keyword)
    results = google_scholar.search_pubs(keyword)  # ← 同步阻塞，无 await
```

search_pubs() 是同步函数，内部是纯 Python 执行 + HTTP 请求，**没有任何 `await` 让出控制权**。

```
时间轴：

Event Loop 线程
│
├─ handle_call_tool() 开始
│   └─ search_pubs() ← 卡在这里执行 5 秒，CPU 被占用
│       └─ HTTP请求... 等待... 解析... （全程无 await）
│
│   ← 这 5 秒内 Event Loop 完全被占用，无法处理任何其他事情
│
├─ handle_list_tools() 请求进来了... 排队等待 ❌
├─ 其他 tool_call 进来了... 排队等待 ❌
│
└─ search_pubs() 终于返回，Event Loop 恢复
```

## 3.问题修复

### 1.修复内容

```python
@server.list_tools()
async def handle_list_tools() -> list[types.Tool]:
    """
    List available tools.
    Each tool specifies its arguments using JSON Schema validation.
    """
    return [
        types.Tool(
            name="search-arxiv",
            description="Search arxiv for articles related to the given keyword.",
            inputSchema={
                "type": "object",
                "properties": {
                    "keyword": {"type": "string"},
                },
                "required": ["keyword"],
            },
        ),
        types.Tool(
            name="search-google-scholar",
            description="Search google scholar for articles related to the given keyword.",
            inputSchema={
                "type": "object",
                "properties": {
                    "keyword": {"type": "string"},
                },
                "required": ["keyword"],
            },
        )
    ]


@server.call_tool()
async def handle_call_tool(
        name: str, arguments: dict | None
) -> list[types.TextContent | types.ImageContent | types.EmbeddedResource]:
    """
    Handle tool execution requests.
    Tools can modify server state and notify clients of changes.
    """
    if name != "search-arxiv" and name != "search-google-scholar":
        raise ValueError(f"Unknown tool: {name}")

    if not arguments:
        raise ValueError("Missing arguments")

    keyword = arguments.get("keyword")

    if not keyword:
        raise ValueError("Missing keyword")

    # Notify clients that resources have changed
    await server.request_context.session.send_resource_list_changed()

    formatted_results = []
    if name == "search-arxiv":
        arxiv_search = ArxivSearch()
        # Run sync search in thread pool to avoid blocking the event loop
        formatted_results = await asyncio.to_thread(arxiv_search.search, keyword)
    elif name == "search-google-scholar":
        google_scholar = GoogleScholar()
        # Run sync search in thread pool to avoid blocking the event loop
        formatted_results = await asyncio.to_thread(google_scholar.search_pubs, keyword=keyword)

    return [
        types.TextContent(
            type="text",
            text=f"Search articles for {keyword}:\n"
                 + "\n\n\n".join(formatted_results)
        ),
    ]
```

改用**`asyncio.to_thread`** 之后

```python
results = await asyncio.to_thread(google_scholar.search_pubs, keyword)
#         ↑ await 让出控制权，同步函数跑在另一个线程里
```

```
时间轴：

Event Loop 线程              Worker 线程
│                            │
├─ handle_call_tool() 开始   │
│   └─ to_thread() ─────────► search_pubs() 在这里跑
│   └─ await ← 让出控制权    │  （不占用 Event Loop）
│                            │
├─ handle_list_tools() 进来  │
│   └─ 立即返回 tools 列表 ✅ │
│                            │
├─ 其他 tool_call 进来        │
│   └─ 也放入线程池执行 ✅    │
│                            │
└─ Worker 完成，await 恢复结果◄─ search_pubs() 返回
```

### 2.问题总结

asyncio 的 `await` 是协程让出 CPU 的一种方式，同步阻塞代码直接运行在 Event Loop 线程上，期间整个线程被独占，`list_tools`、其他 `tool_call` 全都无法执行。
